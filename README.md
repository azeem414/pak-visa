# Direct Route: German student visa guide for Pakistani applicants

A single-page guide to applying for a German student visa from Pakistan without an agent. It walks through the steps in order, links each one to its source, and includes a checklist for spotting agent scams.

Live site: https://azeem414.github.io/pak-visa/

This is an independent guide. It is not an official site and not legal advice.

## What is in the repo

| File | Purpose |
|---|---|
| `index.html` | The whole site: HTML, CSS and a small script for the scam checklist |
| `README.md` | This file |

There is no build step, framework or backend. The scam checklist runs in the browser and does not store or send anything.

## Run it locally

Open `index.html` in a browser. No server is needed.

## Deploy

The site is served by GitHub Pages from the `main` branch, root folder. Push to `main` and the site updates in about a minute.

## Keeping it accurate

Fees, amounts, checklists and appointment procedures change. When you update the page:

1. Check each figure against the official page it cites.
2. Update the "Last reviewed" date near the top and in the footer.
3. Prefer official sources (German Embassy Islamabad, Federal Foreign Office, DAAD, uni-assist, HEC, IBCC) over news or blog posts.

Figures to recheck first:

- Blocked account amount (currently EUR 11,904, from a provider page rather than an official one)
- National visa fee (EUR 75, paid in cash in rupees at the current exchange rate)
- Decision time (the embassy page's 5 to 10 weeks may be out of date)
- Whether MOFA, apostille or APS stamps are needed in addition to IBCC and HEC attestation
- Claims taken from the Make it in Germany site, which could not be fetched when the page was reviewed
